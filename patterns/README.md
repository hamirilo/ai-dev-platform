# Patterns

UI/UXの設計パターンを蓄積する場所です。

## 役割

> どのように設計するか、どのパターンを選ぶか

毎回ゼロから設計を考え直さなくて済むように、過去に検討した良い設計パターンを蓄積します。

PatternはStandardではありません。「必ずこのUIにする」という拘束力は持たず、プロジェクトに最も適したものを選択するための参照先です。

## 追加基準

以下のすべてを満たすものだけをPatternとして追加します。

1. 実際のプロジェクトで設計に迷った
2. 複数案を検討した
3. 良い解決方法が見つかった
4. 他のプロジェクトでも再利用できそう

「将来必要になるかもしれない」「一般的なベストプラクティスだから」という理由だけでは追加しません。

## Patternに含める情報

各Patternには、そのパターンを選択するために必要な情報を含めます。例えば：

- どのようなケースに向いているか
- どのようなケースでは避けるか
- 選択肢数の目安
- モバイルでの利用
- 具体的なデザイン例やスクリーンショット

## 将来の展望

実際のデザインを見ながら選択できるUIカタログへ発展させることを想定しています。
